# stamptype

Stamp structured JSON type payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/stamptype/

## Install / run

```bash
git clone https://github.com/theworker02/stamptype.git
cd stamptype
node src/cli.js
node --test
```
